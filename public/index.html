📜 Immutable Compliance Policies

Define mandatory behavioral rules, strict prohibitions, and conditional directives with clean reference IDs (POL-xxx).

💡

How Policies Are Enforced on Calls

Policies are compiled into Block 2 of the assistant's prompt. Always rules must be executed on every call (e.g. 2-factor ID verification). Never rules are strict guardrails (e.g. never give medical advice). Conditional rules trigger only when specific circumstances occur. Every policy has a reference ID (e.g. POL-001) allowing precise compliance auditing.

📋 Procedures & Workflow Authorization

Define authorized step-by-step procedures that constrain tool usage. Assistants politely decline anything outside enabled procedures.

💡

How Procedures Authorize & Constrain Assistants

Procedures form Block 3 of the system prompt. Assistants can only perform workflows listed in enabled procedures; if a caller's request falls outside, the assistant strictly and politely declines. Furthermore, procedures authorize specific tools. Each procedure must have at least 1 test scenario to certify.
